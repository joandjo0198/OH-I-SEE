# Reference interface integration

The studio uses a dark green and yellow workspace based on the supplied four-panel reference. Existing plan, fixture, roof and finish tools remain connected to the same document.

- Top navigation: 2D Design, 3D Design, 2D Interior, 3D Interior and Final Home.
- Left panel changes between plan settings, exterior camera/environment controls and the live room list.
- Right panel switches between Products, Materials and Roof without losing edits.
- Furniture cards render the real procedural fixture geometry and start the existing placement tool.
- Capture view gallery creates six thumbnails from the current model. Recapture after changing the design. Thumbnail clicks switch the live camera.
- Export project downloads the plan JSON; Full screen expands the workspace. HD PNG exports remain available in the design tools.

The interface does not substitute photographic references for user-generated geometry. The live model remains a simplified procedural visualization; photorealistic quality and exact manufacturer assets are not supplied by this UI update.

Validation: production build, browser navigation between five modes, six gallery images, room selection, six furniture cards, Materials panel visibility and no reported browser console errors. Browser screenshot capture was unavailable in this session, so no full-interface screenshot is claimed.
